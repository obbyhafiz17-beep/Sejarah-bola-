# Sejarah Bola ⚽

Website arsip cerita sepak bola berbahasa Indonesia. Dibuat dengan HTML, CSS, dan JavaScript vanilla agar ringan, mudah diedit, dan dapat langsung dijalankan melalui GitHub Pages.

## Fitur
- Beranda editorial dengan desain responsive.
- Jelajahi artikel dengan pencarian dan filter kategori.
- Linimasa sejarah sepak bola dengan filter era.
- Arsip pemain legenda dan sejarah klub.
- Artikel cerita dengan bookmark dan fitur berbagi.
- Football Quiz 10 pertanyaan dengan skor terbaik lokal.
- Halaman fakta singkat.
- Bookmark tersimpan di localStorage tanpa login.

## Menjalankan secara lokal
Cukup buka \`index.html\` di browser. Untuk pengalaman terbaik, jalankan melalui server statis lokal atau GitHub Pages.

## Deploy melalui GitHub Pages
1. Buka repository **Settings → Pages**.
2. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch \`main\` dan folder \`/ (root)\`.
4. Klik **Save**. Setelah proses publikasi selesai, GitHub akan menampilkan URL website di halaman Pages.

## Mengubah konten
Data artikel, pemain, klub, timeline, kuis, dan fakta berada di bagian atas file \`app.js\`. Edit array terkait untuk menambah atau memperbarui konten.

## Catatan
- Progress bookmark dan skor kuis disimpan di browser pengunjung melalui localStorage.
- Foto menggunakan URL gambar Unsplash sebagai visual editorial; ganti dengan aset yang lisensinya sesuai sebelum publikasi komersial.
- Pastikan fakta sejarah dan referensi ditinjau kembali ketika menambah artikel.
